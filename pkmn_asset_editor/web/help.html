What is this?

Your Pokémon game is made out of lots of files: pictures, maps, and little programs called scripts that say what happens (who talks, who battles you, what you find). This tool lets you change those files with your mouse, and then play your game to see the change.

  • 🎨 Graphics: every picture in the game. Pokémon, trainers, items, map tiles, battle effects.
  • 🗺️ Maps: towns, routes, caves and houses, and the people, doors and signs in them.
  • ▶ Test in game: builds your game and plays it right in your browser.
Hover over any button or field to see what it does.

You can't break anything

  • Nothing changes until you press Save.
  • Made a mess? Undo (or Ctrl+Z) goes back one step. Undo all changes (maps) and Undo all my changes (pictures) put things back to how they were.
  • What I changed shows a before/after picture of everything you edited.
  • Check for problems tells you about mistakes (like a picture that's the wrong size) before they cause trouble in the game.

Change a Pokémon's picture

  1. Open 🎨 Graphics and type the Pokémon's name in the search box, for example mudkip.
  2. Click the picture you want to change (front, back, shiny, icon…).
  3. Either draw on it with the Pencil, or press Replace with image… and pick a picture you made.
  4. Press Save drawing if you drew on it.
Game pictures can only use 16 colours, and the first colour in the palette is see-through. If your picture has other colours, the tool picks the closest ones. Tick use my image's colours to change the palette to your colours instead.

Change colours

Every picture uses a palette: a list of 16 colours. Change a colour in the palette and the picture changes everywhere it's used.

  1. Open the picture in 🎨 Graphics.
  2. Under Palettes, Shift+click (or double-click) a colour square and pick a new colour.
  3. Press Save palette.
Want a shiny version? Search for shiny: shiny palettes are separate files.

Paint a map

Maps are made of blocks: 16×16 squares like grass, path, water, a piece of a roof.

  1. Open 🗺️ Maps and pick a map on the left.
  2. In the Blocks tab on the right, click a block. Drag across several blocks to pick a bigger piece, like a whole tree or house.
  3. With 🖌 Paint, click or drag on the map. 🪣 Fill fills an area.
  4. To copy something already on the map, use Copy blocks and drag over it, then paint it somewhere else.
  5. Use Walls to choose where the player can and can't walk. Red = blocked.
  6. Press Save.

Add a house you can walk into

  1. Paint a house on the map (copy one with Copy blocks), or press Import art… in the Blocks tab to turn your own drawing into blocks.
  2. Press New map / house… at the top. Pick an inside to copy (for example PetalburgCity_House1) and give it a name. You can now decorate the inside.
  3. Go back to your town. Press + Door and click the house's door.
  4. Set Goes to map to your new house, then press Make two-way. Now the door leads inside, and the inside door leads back out.
  5. Make the house's walls blocked with Walls, then Save and ▶ Test in game.

Add a person who talks

  1. Press + Person above the map and click where they should stand.
  2. On the right, set Looks like (for example OBJ_EVENT_GFX_BOY_1) and How it moves (for example MOVEMENT_TYPE_WANDER_AROUND). Start typing and pick from the list.
  3. Press New script… and type what they should say. The tool writes the script for you.
  4. Want to change the words later? Press Open script. The text is on the .string "…" lines. \n starts a new line and \p a new box.
To make them a trainer, set Is a trainer? to TRAINER_TYPE_NORMAL and Sees you from to how many tiles they can see (like 3). Their script then needs a trainerbattle line. Look at a trainer on a route to copy one.

Add a sign or hidden item

  1. Press + Sign and click where the sign is.
  2. Press New script… and type what the sign says.
  3. For a hidden item instead, set Kind to hidden_item, then pick the item and a flag (each hidden item needs its own flag, so it can only be found once).

Test your game

  1. Click a spot on the map where you want to start (or select a person or door).
  2. Press ▶ Test in game, then Build & play.
  3. Move with the arrow keys. Z = A, X = B, Enter = Start.
  4. Changed something? Press Build & play again to see it.
Building the first time can take a few minutes. After that, small changes build in seconds.

Test later in the story

You don't have to replay the whole game to test the part you're working on.

  • How far into the story? Pick a chapter, like Rustboro City: Badge 1. You start with the badges and the things you need by then (HMs, bikes, key items). Tick Also give the extra items for everything from item balls, hidden items and gifts too. Open See the list to untick anything you don't want.
  • Checkpoints are saved games. Press Save checkpoint… while testing to keep your spot, and pick it next time under Where do you start? You can also load a .sav file from your emulator.
  • Added your own maps? In Map settings, choose which Story chapter each map belongs to, or make new chapters.

Test a battle with your own team

  1. In the test window, open Your team.
  2. Type a Pokémon (like mudkip), its level, and if you want a held item and up to 4 moves.
  3. Tick Replace my team to use only these Pokémon.
  4. Press Build & play and walk up to the trainer.

Make water and flowers move

Moving water, flowers and waterfalls are animations: a few pictures shown one after another.

  1. On a map, tick animate above the map to see them move.
  2. Open the Animations tab. Each animation shows its frames.
  3. Speed: smaller number = faster (60 = one picture per second).
  4. Play order: which frames to show, like 0 1 2 1.
  5. Pick a frame and press Replace art… to draw your own, or Add frame (copy) to add one.
  6. To animate your own blocks, select the block in the Blocks tab, then in New animation press From selected block and Create animation.

Check and build your game

  • Check for problems looks for mistakes in everything you changed.
  • Build game makes the game file (.gba) you can play in any emulator.

Get help from an AI

AI assistants (like Claude) can use this tool too. Run pae mcp to connect one, or ask it to read pae guide. It can paint maps, write dialogue, change graphics and test the game, and you can see everything it did under What I changed.

Words you'll see

Tile
A tiny 8×8 square of pixels. Everything on a Game Boy Advance is built from tiles.
Block (metatile)
A 16×16 map square made from 4 tiles (8 counting the top layer), like grass or a piece of roof. The player walks one block per step.
Tileset
The set of tiles and blocks a map can use. Towns share a primary one (grass, trees, water) and each has its own secondary one (its buildings).
Palette
A list of 16 colours a picture uses. Change the palette and the picture changes colour.
Sprite
A picture that moves around, like the player or a Pokémon.
Event
Anything on a map that does something: a person, a door, a sign, or a step trigger.
Door / warp
A spot that takes you to another map.
Step trigger
An invisible spot that starts a script when you step on it (like a rival appearing).
Script
The instructions for what happens: talking, battles, giving items, cutscenes.
Flag
An on/off switch the game remembers, like "got Badge 1" or "picked up this Potion". Names start with FLAG_.
Variable (var)
A number the game remembers, used to track how far a story has got. Names start with VAR_.
Walls (collision)
Where the player can't walk.
Height level (elevation)
Which height something is at (bridges and ledges use it). 3 is normal ground.
Layout
The blocks of a map. Several maps can share one layout (most houses do).
Checkpoint
A saved game you can start tests from.
Chapter
A part of the story (like "Badge 1"), used to start tests later in the game.
Build
Turning all the files into a playable game.
ROM
The game file (.gba) an emulator plays.
Constant
A name the game uses instead of a number, like SPECIES_MUDKIP or ITEM_POTION. Start typing in a field and pick one from the list.
