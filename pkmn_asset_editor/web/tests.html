How to make a test

  1. On 🗺️ Maps, open ▶ Test in game and start where the test should begin (a map, a checkpoint, a chapter, a team).
  2. Play what the test should check: walk, talk, start a battle and win it…
  3. Press 🔴 Save as a test. What the game shows at that moment is what every replay must show.

Or from the command line: pae test record "beat roxanne" RustboroCity --team "SPECIES_MUDKIP lv20" --battle TRAINER_ROXANNE_1 --inputs "A, wait 20, …" --watch-trainer TRAINER_ROXANNE_1

Check every change on GitHub

Adds .github/workflows/pae.yml to your game. When you push to GitHub (or someone opens a pull request), GitHub builds the game, runs pae check and replays these tests, and shows ✅ or ❌ next to the commit. The screens are kept as a download on the run's page.
